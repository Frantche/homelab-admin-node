# Notes techniques

La documentation utilisateur canonique et publiée se trouve dans
`site/content/en/docs/`. Ce dossier est réservé aux notes de conception,
historique de décisions et plans techniques qui ne font pas partie du parcours
utilisateur.

Lorsqu'une note décrit encore une procédure opérateur, migrer cette procédure
vers le site puis remplacer la duplication par un lien.
